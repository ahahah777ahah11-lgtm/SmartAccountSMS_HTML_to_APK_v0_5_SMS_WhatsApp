# المحاسب الذكي — رسائل العملاء v0.5

نسخة HTML مخصصة للتحويل بواسطة HTML to APK Builder.

## الجديد
- إرسال رصيد العميل عبر SMS أو WhatsApp.
- زر إرسال SMS وWhatsApp لكل عميل.
- إرسال جماعي للعملاء المحددين.
- قالب رسالة يدعم `{الاسم}` و`{الرصيد}`.
- مفتاح دولة افتراضي لليمن 967 لتنسيق أرقام WhatsApp.
- تحديد الفاصل بين محاولات الإرسال.
- سجل تقدم الإرسال.
- استيراد دفتر الحسابات SQLite مع حذف القائمة القديمة قبل الاستيراد وحفظ الجديدة.
- استيراد CSV مع استبدال البيانات القديمة.
- تعديل وإضافة العملاء.
- إعدادات المؤسسة والعملة والقالب والحفظ التلقائي.

## ملاحظة مهمة عن WhatsApp
HTML/WebView لا يستطيع فرض إرسال WhatsApp في الخلفية بدون تدخل المستخدم أو جسر أصلي/خدمة رسمية. التطبيق يفتح `wa.me` مع الرقم والرسالة جاهزة. الإرسال الجماعي الصامت عبر WhatsApp يحتاج تكاملًا رسميًا (مثل WhatsApp Business Platform) أو جسرًا أصليًا يدعمه الـBuilder.

## SMS
إذا كان HTML to APK Builder يوفر جسرًا أصليًا باسم AndroidAPI/NativeBridge/Android مع `sendSMS(phone, message)` فسيستخدمه التطبيق. وإلا يفتح تطبيق الرسائل برسالة جاهزة.
